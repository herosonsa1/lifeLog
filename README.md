# LifeLog (스마트 라이프로그 & 통합 가계·차계·골프 플랫폼)

자동 SMS/알림 파싱, 스마트 차계부(출퇴근 자동 정합 및 주유 기록), 골프 스코어카드/라커룸 OCR 분석, 지출 다이어리를 통합한 Android 네이티브 애플리케이션입니다.

## 주요 기능
- **통합 다이어리 (Smart LifeLog)**: 소비/지출 및 이동 위치(동 단위 주소) 자동 매핑
- **스마트 차계부**: 집/회사 거점 기반 출퇴근 왕복 주행 자동 분류 및 주유비/연비 통계
- **골프 라이프**: 라커룸 영수증 & 스코어카드 OCR 지능형 자동 분석, 티오프 일정 관리
- **스마트 가계부**: 수입/지출 내역 자동 분석 및 통계
